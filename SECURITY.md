# Security policy

Please do not disclose suspected vulnerabilities in a public issue. Use the
repository's **Security → Report a vulnerability** form to open a private
GitHub security advisory. Include affected versions, reproduction details,
impact, and any known workaround. Do not include secrets or data belonging to
other people.

The maintainer will acknowledge a report as soon as practical, validate and
triage it privately, coordinate a fix and disclosure date, and credit the
reporter when requested and appropriate. There is currently no paid bug bounty
or guaranteed response-time commitment.

Only the latest published minor release receives security fixes while the
project is below version 1.0. Affected older versions may be deprecated instead
of patched. Release and recovery procedures are documented in
[`docs/release.md`](./docs/release.md).
