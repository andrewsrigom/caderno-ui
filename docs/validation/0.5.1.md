# 0.5.1 release

Published on 2026-08-28 from commit
`0c18a9c0ab8d765637ebb25ace64b422aeb9f09d` through the existing Changesets and
npm Trusted Publishing workflow. All six public packages are at `0.5.1`.
Version `0.5.0` was a local candidate, not an npm release.

[Release notes](https://github.com/andrewsrigom/caderno-ui/releases/tag/v0.5.1)
include the upgrade instructions and compatibility changes.

## Verification

- [Main CI](https://github.com/andrewsrigom/caderno-ui/actions/runs/33137218031):
  all 14 jobs passed, including Node 22/24 compatibility, accessibility,
  platform modes, visual regression, packaging and dependency checks.
- [Publication](https://github.com/andrewsrigom/caderno-ui/actions/runs/33137218049):
  the complete release gate passed before publishing the exact six tarballs.
  This includes 131 browser tests, 110 documentation tests, installed React
  18/19 and Astro 5/7 consumers, and Next.js, Vue and Svelte interactions.
- A fresh directory outside the workspace installed all six packages from npm
  at `0.5.1`, without overrides or source links. Vite build, React server
  rendering, Astro build and slot assertions, TypeScript bundler/NodeNext
  checks, and Node imports passed.
- All six npm `latest` tags resolve to `0.5.1`. Downloaded tarballs match their
  registry SHA-512 integrity values and have npm provenance records.
- [Documentation deployment](https://github.com/andrewsrigom/caderno-ui/actions/runs/33137218035)
  passed. The public documentation links to the notes app and Kanban board;
  navigation and opening/cancelling the task dialog were checked without
  creating or clearing browser data.

The hosted apps are static exports. The separate installed `next start`
consumer supplies the SSR evidence; the public demos do not claim SSR hosting.
The earlier [isolated SeniorPath check](0.5.0.md) records the product integration
evidence. This release did not change SeniorPath's development checkout or data.

## Accepted limitations

After reviewing the automated results and the manual checks that could not be
performed, the maintainer explicitly authorized this 0.x publication.
This is a release-specific exception to the manual accessibility gate, not a
record of completed screen-reader testing.

NVDA, VoiceOver, manual 200% zoom, and Windows High Contrast sessions remain
unverified. Automated keyboard, reflow, forced-color and axe checks passed,
but do not establish assistive-technology compatibility. The public validation
page retains this limitation. No new screen-reader support claim is made.
